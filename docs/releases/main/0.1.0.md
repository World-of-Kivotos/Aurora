Aurora 0.1.0

第一个可以装来用的版本。正版登录、版本安装、Mod 管理这条主线已经跑通。

账户与启动：
- 微软正版登录，登录态本地加密留存，下次启动自动续期，不用反复扫码
- 支持外置登录（authlib-injector）
- 一键启动，游戏日志按会话归档，崩了能翻回去看
- 玩家自己关掉游戏不会再被误报成崩溃

版本安装：
- 原版、Forge、NeoForge、Fabric、Quilt 都能装
- 版本隔离默认开启，每个版本的存档、配置、Mod 各归各的，互不串味
- 安装目录可以在装启动器时自己选，游戏文件就放在启动器旁边，搬盘直接整个文件夹拷走

Mod 与资源：
- 同时搜 Modrinth 与 CurseForge，Mod、整合包、资源包、光影、数据包分开浏览
- 装 Mod 时按左边选中的实例自动筛出对得上的加载器与游戏版本，不用自己比对
- 前置依赖会先列出来给你过目，缺哪个一起装
- 装过的东西都记在实例卷宗里，能查来源、能查更新、能回滚到上一个版本
- 同一个 Mod 的旧版本会被自动替换掉，不会两个版本躺在一起把游戏搞崩

其它：
- 内置 Java 管理，缺运行时会提示装哪个
- 启动器自更新，在设置的「关于」里检查
- 能扫到 PCL2、HMCL 等其它启动器的游戏目录，一并接管，不用重新下载

已知问题：
- 国内直连 GitHub 拉更新包偏慢，暂未接镜像源
