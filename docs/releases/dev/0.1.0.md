Aurora 0.1.0（开发版）

第一个走完整条流水线的构建。功能面与稳定版一致，但这条线上的包没有经过完整的装机验证，
装之前请自己留好游戏目录的备份。

这个版本做完的：
- 微软正版登录与外置登录（authlib-injector），登录态本地加密留存并在启动前静默续期
- 原版、Forge、NeoForge、Fabric、Quilt 安装，版本级隔离默认开启
- Modrinth 与 CurseForge 双平台搜索，五类资源分开浏览
- Mod 落位弹层按选中实例过滤加载器与游戏版本，前置依赖成计划一并安装
- 实例卷宗记录来源、版本与安装历史，支持查更新与回滚
- 同工程的旧版本 Mod 自动替换；跨平台重复（同一个 Mod 分别从两个站装过）按 mod_id 兜底识别
- 游戏日志按会话归档，崩溃检测排除了玩家主动退出的情况
- 数据目录便携优先：可写就放在 exe 旁边，随安装位置走
- 启动器自更新，安装包由 CI 用 minisign 私钥签名，客户端以内置公钥校验

这个版本没做完的，装之前请知悉：
- 更新源只有 GitHub Releases 直连，国内拉取偏慢，镜像端点还没接
- 真机端到端验证尚未完整跑过：安装闭环、结束游戏、版本级隔离三条路径以自动化测试为主
- CurseForge 侧的更新检查仍逐个查询（该平台没有批量端点），实例里 Mod 多时这一步会慢
- 整合包导入尚未实现，目前只能浏览与下载

给要动手改的人：
- 三处版本号以 app/src-tauri/tauri.conf.json 为准，用 node scripts/version.mjs set 改
- 发行说明写在 docs/releases/<频道>/<版本号>.md，缺了流水线会失败，见该目录的 README
